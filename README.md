# Book Library

Book Library is a simple web application that allows users to organize
and keep track of their personal book collection.

## Features

- Add a new book
- View saved books
- Edit book information
- Delete books
- Track reading status

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
- Netlify
- GitHub

## Database

The application uses Supabase to store book information, including:

- Book title
- Author
- Genre
- Reading status

## CRUD Functionality

The application supports the four basic CRUD operations:

- Create: Add a new book
- Read: Display books stored in the database
- Update: Edit existing book information
- Delete: Remove a book from the library

## Deployment

The application is deployed using Netlify and connected to the GitHub
repository for deployment.
